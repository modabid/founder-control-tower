## Phase-1 Chain

Domain agents produce deterministic-grounded specialist briefs. SENTINEL audits/challenges. ORBIT synthesizes and resolves priorities. ATLAS presents founder decisions.

## Future Training / Playbook Layer

Each agent should eventually have an auditable founder-instruction registry containing:

- exact instruction/rule;
- agent/domain scope;
- date/version;
- active/inactive state;
- conflict with locked governance/business rules;
- tests proving expected behavior.

Founder instructions may refine operating playbooks but cannot silently override locked accounting/data/governance contracts.
