# Apps Script Transitional Runtime

This folder contains the current locked Phase-1 Apps Script intelligence code and legacy bridge code.

It is **not** the permanent architecture.

## Structure

- `snapshots/` deterministic specialist packets
- `runners/` specialist AI runners
- `hierarchy/` SENTINEL / ORBIT / ATLAS
- `orchestrator/` Phase-1 final orchestration/caching/governance
- `meta/` current available Meta API source code
- `runtime/` pending export of shared live runtime files
- `tests/` Apps-Script-side tests

See root `MIGRATION_CHECKLIST.md` for missing live runtime files.
